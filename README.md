# SOC Alert Investigations Portfolio

A collection of security alert investigations completed during a hands-on SOC simulator experience on TryHackMe. Each case includes the alert details, investigation steps, SIEM queries used, findings and final verdict. 

<h2> 🎯 Purpose</h2>

This repository demonstrates my ability to:
- Triage and investigate phishing/security alerts
- Write and interpret SIEM search queries (Splunk SPL)
- Analyse email headers/content, Indicators of Compromise (IOC), and log data (email, proxy, firewall)
- Distinguish true positives from false positives 
- Document findings clearly and make escalation decisions 
- Recommend remediation actions 

<h2>🛠️ Tools & Skills Used</h2>

- SIEM (Splunk) log searching and correlation
- Email header/IOC analysis
- Phishing indicator identification (typosquatting, spoofed domains, urgency tactics)
- Firewall/proxy log analysis
- Incident documentation and reporting
